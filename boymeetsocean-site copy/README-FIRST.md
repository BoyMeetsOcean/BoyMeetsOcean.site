# Boy Meets Ocean Website — Beginner Guide

You do not need to know how to code to manage the finished version of this site.

## What is included

- Home page
- About Atticus page
- “Where I Am Now” page
- Starter shop page
- Social links
- Story/blog cards
- Mobile-friendly navigation
- A single easy content file for routine updates

## The easiest way to preview it

1. Unzip the folder.
2. Open `index.html` in Safari or Chrome.
3. Click through the pages.

## The one file you will update most often

Open `content.js` in any plain-text editor.

That file contains:
- follower count
- current location
- last-updated date
- next destination
- social links
- story cards
- products
- image filenames

Only change the words inside quotation marks. Save the file and refresh the webpage.

## Replacing the placeholder photos

1. Put your photos in the `assets` folder.
2. Use simple filenames such as:
   - `atticus-hero.jpg`
   - `atticus-about.jpg`
   - `bahamas-dive.jpg`
3. In `content.js`, replace the old placeholder filename with the new filename.

Example:

`heroImage: "assets/atticus-hero.jpg",`

## Best beginner-friendly way to publish

Recommended route:

1. Use **Shopify** for products, checkout, payments, shipping, and inventory.
2. Use **Shopify Buy Buttons** inside this custom site, or rebuild this design as a Shopify theme.
3. Use **Cloudflare Pages**, **Netlify**, or **GitHub Pages** to host the public website.
4. Connect `boymeetsocean.com` by changing the domain’s DNS records.

For the least technical path, hire a freelancer for the one-time launch and keep routine content updates in `content.js`.

## Easier long-term editing option

For truly no-code updates, the next version should connect the website to a content-management system such as:

- Sanity
- Shopify Metaobjects
- WordPress
- Webflow CMS

My strongest recommendation for this project is:

- Shopify for the store
- Sanity or Shopify Metaobjects for stories and “Where I Am”
- This design as the front end

That gives you simple forms instead of editing files.

## Important safety recommendation

Because Atticus is a minor, do not publish a precise live position. Use a broad place such as a town, island, region, or cruising area, and update it after leaving when necessary.

Also:
- Keep business email parent-managed.
- Do not list a personal phone number.
- Use a parent-controlled payment account.
- Add privacy, terms, shipping, returns, and contact pages before accepting orders.
- Obtain permission before reposting identifiable images of other children.

## Suggested launch order

1. Replace placeholder photos.
2. Add real social links.
3. Finalize About page wording.
4. Choose 3–6 initial products.
5. Set up Shopify.
6. Add legal and store policy pages.
7. Connect email signup.
8. Connect domain.
9. Test on phone, tablet, and desktop.
10. Launch and link it in every social bio.

Give them the entire folder and say:
